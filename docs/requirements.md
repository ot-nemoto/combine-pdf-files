# 要件定義

## 機能要件

### PDF ファイル入力

- ファイル選択ダイアログからの PDF アップロード（複数同時選択可）
- ドラッグ＆ドロップによる PDF アップロード（複数同時対応）
- PDF 以外のファイルは無視する

### ページ管理

- アップロードされた PDF をページ単位に分解して一覧表示する
- 各ページのプレビューを iframe で表示する
- ページの並び順を上下ボタンで変更できる
- ページを個別に削除できる
- ページを時計回り・反時計回りに 90° 単位で回転できる

### PDF 結合・出力

- 2 ページ以上選択時に結合ボタンが有効になる
- 結合処理はクライアントサイドで実行する（pdf-lib）
- 結合完了後、プレビューとダウンロードリンクを表示する
- 出力ファイル名は `merged.pdf`

### エラーハンドリング

- 処理失敗時にユーザーフレンドリーなエラーメッセージを表示する

## 非機能要件

- すべての PDF 処理はクライアントサイドで完結すること（サーバーへのファイル送信なし）
- ダークモード対応
- GitHub Pages で静的サイトとしてホスティング可能であること
